SQLite 复现库缩减 / 脚本依赖核查服务

缩减入口：上传受限结构的 SQLite 库与确定性脚本，生成 1-最小复现库； 依赖核查：提交 2～4 段入仓 SQL，只分析不运行，输出读写表、外键隐含读取、 冲突先后关系与可并行批次。

输入约束

  • 至多 3 张普通表，无触发器、无视图、无虚拟表；全部表共至多 60 行。
  • 主键与外键均为 单列 INTEGER，外键必须引用目标表主键，允许循环引用。
  • 上传库现有数据必须已满足外键约束；脚本不得访问外部文件（ATTACH/PRAGMA/扩展等被拦截）。
  • 复现判定：SQLite 扩展错误码 与完整错误文本完全一致；其它错误不算复现。
  • 每次试跑使用独立副本，先 COMMIT 再失败也不会污染原件、后续试跑或下载库。

核查规则

  • 上传与缩减入口相同约束的 SQLite 库（≤3 表、≤60 行、单列 INTEGER 主键/外键、外键有效）。
  • 按既定顺序提交 2～4 段 SQL；只接受查询（SELECT/VALUES/WITH）、对现有表的 增删改（INSERT/UPDATE/DELETE/REPLACE，支持 WITH 子查询）与事务控制 （BEGIN/COMMIT/ROLLBACK/SAVEPOINT/RELEASE）。
  • 只分析不运行：语句仅做 EXPLAIN 准备，库以只读方式打开，原库与已有缩减结果均不变。
  • 外键约束引起的隐含读取计入：插入/更新读父表主键、删除/更新父表读子表外键列（含自引用）。
  • 按提交顺序为读写或写写同表的语句建立先后关系，并给出层内无冲突、依赖上可并行的批次。
  • 任何语句无法判定时指出语句序号与行列位置，不输出部分排程。
